# Supplementary numerical data

Run `python scripts/reproduce_supplementary_tables.py` from the repository root.
This recalculates auxiliary table scores from stored trajectories: the separate 2008 scalar-diffusion comparison,
the illustrative size ensemble, and storage-consistent uptake-coefficient ratios.
The scalar-law parameters, uptake traces and geometry/refinement tables accompany those calculations.
These are archived-curve calculations; fresh primary particle-model runs use the two main reproduction commands.
