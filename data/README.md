# Faner experiment

`final.json` gives the archived cases, exact arguments, source variants and archive hashes.
The retained reference, refinement and transfer-factor cases support the article's Faner comparison.
Digitized observations are in `paper/analysis/datasets/faner2019_v2/`.
Run `python scripts/reproduce_final_reference.py --extract-only` to obtain the native records,
or select a calculation with `--case`. The prescribed DT experiment is in `matched_pd/`.
