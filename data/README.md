The XZ-compressed tar archive holds unchanged raw result/checkpoint bytes,
digitized readings, the prescribed bath/feed, current derived indexes/audits,
and the historical verification/sensitivity evidence cited by the supplement.
Unselected Faner attempts and duplicated presentation files are omitted.

`evidence.json` pins the archive. `EVIDENCE_MANIFEST.sha256` inside it pins
each member. The normal reproduction command extracts and verifies these
files automatically; extracted paths are ignored by Git. To inspect evidence
without running numerical checks:

    python paper/analysis/harness/submission_evidence.py

Current Faner data include all accepted parent-result links and their
checkpoint/command records. Current DT data retain the native refused birth
attempts and recovery diagnostics. This packaging changes no native physical
law, accepted state, numerical gate, or original run-record content. The
portable study index excludes references to unselected attempts. Historical
operator/sensitivity configurations are identified by their dated folders.
